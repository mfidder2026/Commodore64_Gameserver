# Release

`bblan.d64`: the lobby (`BBLAN`) and the game for the Ultimate (`BBU`), the WiC64 (`BBW`) and RR-Net in VICE (`BBR`).
Load `BBLAN` and run it; see [../docs/MANUAL.md](../docs/MANUAL.md).

The game server is built from source: `cd server && dotnet run --project src/C64GameServer -c Release`.
